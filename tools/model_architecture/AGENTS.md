# 模型架构绘图工具的后续维护

- 开始新模型或修改绘图逻辑前，阅读 [WORKFLOW.md](WORKFLOW.md)；新任务可用 `init-study` 生成待审阅来源与检查模板。
- 保持来源／事实、模型专属拓扑、展示排版、原生导出四层分离。通用工具不能凭模型名、配置类默认值或权重名称自动声称恢复完整模型。
- 复用 `model_diff.py` 和 `routing.py`，不要复制某个模型的RoPE、归一化、窗口或门控假设到另一模型。来源下载按唯一ID保存，防止同名文件覆盖。
- 正式PNG只能直接由同名原生draw.io导出，保留layout与export记录。改变图结构或XML后重新导出并核验，不能独立修补PNG。
- 图上短标签、说明入description；直线优先并避让节点；颜色差异与模型事实必须有独立证据，不让样式变化改写计算图。
- 运行相关检查；不声称未执行的权重形状核验、GPU推理、数值等价或飞书导入。提交与推送遵循用户已授权的仓库／分支，不自行发布环境。

- 每个算子按视觉复杂度、名称／维度长度和接口选择矩形宽高；简单算子紧凑、投影按维度分行、复合模块留空间。保持前后中心线、并行分支的层级和合理留白，禁止机械等宽等高或一味缩字。可复用 `operator_layout.py`，尺寸变化后重跑routing和原生导出检查。
